# Nido — asistente familiar

Primer MVP móvil-first de un asistente familiar para convertir mensajes, circulares y notas en una agenda accionable.

## Qué incluye

- Bandeja de entrada rápida para pegar texto.
- Clasificación local simulada de evento/tarea.
- Agenda familiar.
- Marcado de tareas completadas.
- Diseño responsive orientado a móvil.
- Datos demo para visualizar el producto desde el primer arranque.

## Ejecutar

```bash
npm install
npm run dev
```
